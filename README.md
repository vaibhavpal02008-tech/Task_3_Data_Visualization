# 📊 Retail Sales Data Visualization Dashboard

### CODE_ALPHA Internship — Task 3

A Python-based data visualization project that transforms raw retail sales data into meaningful charts and an interactive dashboard. The project helps users understand sales performance, product categories, monthly trends, and customer purchasing patterns.

## 🚀 Project Overview

This project uses data visualization techniques to explore a retail sales dataset and present insights in an easy-to-understand format. It includes static charts and an interactive dashboard built with Streamlit.

## 🎯 Objectives

- Transform raw data into clear visualizations.
- Compare sales across product categories.
- Analyze monthly sales trends.
- Explore customer purchasing patterns.
- Build an interactive dashboard for data exploration.
- Support data-driven decision-making.

## 🛠️ Technologies Used

- **Python** — Programming language
- **Pandas** — Data processing and analysis
- **Matplotlib** — Charts and graphs
- **Seaborn** — Statistical visualizations
- **Plotly** — Interactive charts
- **Streamlit** — Interactive dashboard

## 📈 Visualizations

### 1. Sales by Product Category
Compares total sales across product categories to identify the category with the highest sales.

### 2. Monthly Sales Trend
Shows how total sales change over time.

### 3. Category and Gender Analysis
Compares average transaction amounts across product categories and gender groups.

### 4. Customer Age vs Transaction Amount
Explores the relationship between customer age and transaction amount.

## 📊 Interactive Dashboard

The Streamlit dashboard includes:

- Total sales
- Number of transactions
- Average transaction amount
- Units sold
- Product category filters
- Gender filters
- Interactive charts
- Filtered data table
- CSV download option

## 💻 Installation and Setup

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your repository URL.

### Step 2: Open the project folder

```bash
cd CODE_ALPHA_Task3_Data_Visualization
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Generate visualizations

```bash
python visualization.py
```

### Step 5: Run the dashboard

```bash
python -m streamlit run dashboard.py
```

Open the local URL displayed in the terminal to use the dashboard.
